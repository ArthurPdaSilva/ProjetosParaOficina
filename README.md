👨‍🏫 Oficina de C# — IFPB Monteiro
Este repositório reúne os projetos desenvolvidos durante a Oficina de C# que ministrei no IFPB - Campus Monteiro.
A proposta foi introduzir conceitos fundamentais da linguagem C# de forma prática, utilizando a construção de aplicações simples e funcionais.

🛠 Projetos apresentados:
🧮 Calculadora Básica
Projeto de console que permite realizar operações matemáticas simples (adição, subtração, multiplicação e divisão).

✅ Aplicativo ToDo (Tarefas)
Aplicação em C# com foco em organização de tarefas: adicionar, listar e remover itens da lista.
